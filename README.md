# ️ Network Disk Analyzer (FullScan)

PowerShell-скрипт для анализа сетевого диска, поиска старых и больших файлов, и генерации красивых отчётов для пользователей и руководства.

> **Цель проекта:** Помочь IT-отделам организаций освободить место на файловых серверах без конфликтов с сотрудниками — через автоматизированный сбор данных и персональные уведомления.

---

## ✨ Возможности

- 🔍 **Сканирование папок** — рекурсивный анализ всех подпапок и файлов
- 👤 **Определение владельцев** — автоматическое выявление владельца каждой папки через ACL
- 📊 **Гибкие критерии** — настройка возраста файлов и минимального размера
- 📝 **CSV-отчёт** — сводная таблица для Excel по всем папкам и пользователям
- 📄 **Персональные TXT-отчёты** — индивидуальные списки файлов для каждого пользователя
-  **Красивые HTML-отчёты** — сводный и персональные отчёты с графиками и цветовой индикацией
- 💾 **Подсчёт освобождаемого места** — явное указание, сколько GB можно освободить
- ️ **Безопасность** — скрипт работает только в режиме чтения, ничего не удаляет и не перемещает
- 💪 **Устойчивость к прерываниям** — при остановке (Ctrl+C) уже обработанные данные сохраняются
-  **Логирование** — полный лог работы для аудита

## ⚙️ Требования

- **ОС:** Windows Server 2012 R2 / Windows 10 / Windows 11 и выше
- **PowerShell:** 5.1+ (Windows PowerShell)
- **Права:** Запуск от имени администратора (для чтения ACL всех папок)
- **Доступ:** Права на чтение целевой папки и всех её подпапок

---

$SharePath  = "G:\share\net"   # Путь к папке для сканирования
$DaysOld    = 730                     # Критерий "старости" файла (в днях)
$MinSizeMB  = 50                      # Минимальный размер файла (в МБ)
$OutputDir  = "C:\temp\reports"       # Папка для TXT-отчётов
$HtmlDir    = "C:\temp\html_reports"  # Папка для HTML-отчётов
$SummaryCSV = "C:\temp\SummaryReport.csv"  # Путь к CSV-файлу
$LogFile    = "C:\temp\FullScanLog.txt"    # Путь к лог-файлу
$Deadline   = (Get-Date).AddDays(14)  # Дедлайн для пользователей (автоматически)
