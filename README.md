
PowerShell-скрипт для **рекурсивного анализа** сетевого диска, поиска старых и больших файлов, определения реальных владельцев и генерации красивых отчётов для пользователей и руководства.

> **Цель проекта:** Помочь IT-отделам организаций освободить место на файловых серверах без конфликтов с сотрудниками — через автоматизированный сбор данных и персональные уведомления.

---

## ✨ Возможности

- 🔍 **Рекурсивное сканирование** — анализ **всех папок всех уровней вложенности**, а не только корневых
- 👤 **Определение реальных владельцев** — два режима:
  - **Быстрый** (по папкам) — владелец папки = владелец всех файлов в ней
  - **Точный** (по файлам) — индивидуальный владелец для каждого файла
- 📊 **Гибкие критерии** — настройка возраста файлов и минимального размера
- 📝 **CSV-отчёт** — сводная таблица для Excel с относительными путями всех папок
- 📄 **Персональные TXT-отчёты** — индивидуальные списки файлов для каждого пользователя
- 🎨 **Красивые HTML-отчёты** — сводный и персональные отчёты с графиками, медалями 🥇🥉 и цветовой индикацией
- 💾 **Подсчёт освобождаемого места** — явное указание, сколько GB можно освободить
- ️ **Безопасность** — скрипт работает только в режиме чтения, ничего не удаляет и не перемещает
- 💪 **Устойчивость к прерываниям** — при остановке (Ctrl+C) уже обработанные данные сохраняются
- 📋 **Логирование** — полный лог работы для аудита
-  **Промежуточное сохранение** — CSV обновляется каждые 50 папок

## 🚀 Быстрый старт

### 1. Скачайте скрипт

Cкачайте файл `FullScan.ps1` напрямую из репозитория.

### 2. Настройте параметры

Откройте `FullScan.ps1` и измените блок настроек в начале файла:

```powershell
$SharePath      = "G:\share\net"   # Путь к сканируемой папке
$DaysOld        = 730                     # Возраст файлов в днях (730 = 2 года)
$MinSizeMB      = 50                      # Минимальный размер файла в МБ
$FileOwnerMode  = $false                  # $false = быстро (по папкам), $true = точно (по файлам)
```

### 3. Исправьте кодировку (ВАЖНО!)

Windows PowerShell 5.1 имеет проблемы с кириллицей в UTF-8 без BOM. Выполните:

```powershell
$content = Get-Content ".\FullScan.ps1" -Raw -Encoding UTF8
$content | Out-File ".\FullScan.ps1" -Encoding UTF8
```

### 4. Запустите

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\FullScan.ps1
```

## ⚙️ Параметры настройки

Все параметры находятся в начале файла `FullScan.ps1`:

```powershell
$SharePath      = "G:\share\net"   # Путь к папке для сканирования
$DaysOld        = 730                     # Критерий "старости" файла (в днях)
$MinSizeMB      = 50                      # Минимальный размер файла (в МБ)
$OutputDir      = "C:\temp\reports"       # Папка для TXT-отчётов
$HtmlDir        = "C:\temp\html_reports"  # Папка для HTML-отчётов
$SummaryCSV     = "C:\temp\SummaryReport.csv"  # Путь к CSV-файлу
$LogFile        = "C:\temp\FullScanLog.txt"    # Путь к лог-файлу
$FileOwnerMode  = $false                  # Режим определения владельца
$Deadline       = (Get-Date).AddDays(14)  # Дедлайн для пользователей (автоматически)
```

### Рекомендации по настройке

| Сценарий | DaysOld | MinSizeMB | FileOwnerMode |
|----------|---------|-----------|---------------|
| Агрессивная чистка | 365 (1 год) | 10 | false |
| Стандартная чистка | 730 (2 года) | 50 | false |
| Только очень старые | 1095 (3 года) | 100 | false |
| Только большие файлы | 365 | 500 | false |
| Максимальная точность | 730 | 50 | **true** |

##  Как работает рекурсивное сканирование

### Режим по папкам (`$FileOwnerMode = $false`) — БЫСТРО ✅

1. Скрипт рекурсивно получает **все папки всех уровней** через `Get-ChildItem -Recurse`
2. Для каждой папки определяет её владельца через `Get-Acl`
3. Сканирует файлы **только в этой папке** (без дублирования)
4. Все файлы приписываются владельцу папки

**Скорость:** минуты-часы  
**Точность:** ~95% (в большинстве случаев владелец папки = владелец файлов)

### Режим по файлам (`$FileOwnerMode = $true`) — ТОЧНО ⚠️

1. Скрипт рекурсивно получает все папки
2. Для **каждого файла** отдельно вызывает `Get-Acl`
3. Владелец определяется индивидуально

**Скорость:** часы-дни (очень медленно)  
**Точность:** 100%

**Рекомендация:** используйте режим по папкам (`$false`) для большинства задач.

## 🛡️ Безопасность

**Скрипт полностью безопасен для ваших данных:**

- ✅ **Только чтение** — скрипт использует только команды `Get-ChildItem`, `Get-Acl`, `Measure-Object`
- ❌ **Нет удаления** — в коде отсутствуют команды `Remove-Item`, `Move-Item`, `Copy-Item`
- ❌ **Нет изменений** — не модифицирует файлы, папки или права доступа
-  **Логирование** — все действия записываются в лог-файл
- 💾 **Промежуточное сохранение** — CSV обновляется каждые 50 папок, данные не теряются при прерывании

### Проверка безопасности

Вы можете убедиться в этом самостоятельно:

```powershell
Select-String -Path ".\FullScan.ps1" -Pattern "Remove-|Move-|Copy-|Set-|New-Item"
```

Команда должна вернуть пустой результат — в скрипте нет опасных операций.

## ❓ FAQ

### Скрипт долго работает, это нормально?

Да. Скорость зависит от:
- Количества папок и файлов (тысячи папок = часы работы)
- Скорости диска (сетевой диск медленнее локального)
- Выбранного режима владельца (`$true` работает в 10-100 раз медленнее)

**Рекомендация:** запускайте в нерабочее время.

### Что делать, если скрипт прервался?

Нажмите Ctrl+C — скрипт сохранит уже обработанные данные. Запустите его снова, он начнёт с начала, но вы не потеряете предыдущие результаты (CSV перезапишется).

### Почему некоторые папки показывают владельца "unknown"?

Возможно, у учётной записи, от которой запущен скрипт, нет прав на чтение ACL этой папки. Запустите скрипт от имени администратора домена.

### Можно ли сканировать несколько дисков сразу?

В текущей версии — нет, только одна папка за раз. Но вы можете изменить `$SharePath` и запустить скрипт повторно.

### Как изменить язык отчётов на русский?

Откройте `FullScan.ps1` и замените английские тексты в блоках HTML на русские. Все текстовые строки находятся в секциях генерации HTML.

### Чем отличается режим `$FileOwnerMode = $true` от `$false`?

- **`$false` (по папкам):** владелец определяется один раз для папки, все файлы внутри приписываются ей. Быстро, но если в папке есть файлы от разных пользователей — они все будут приписаны владельцу папки.
- **`$true` (по файлам):** для каждого файла вызывается `Get-Acl`. Точно, но очень медленно (может занять дни на больших дисках).
